# Агрегаты

## Агрегат: Бронь (Booking)
**Корень**: `Booking`
**Состав**: `TimeRange` (значение), `Status` (значение).

### Инварианты
*   `ends_at > starts_at` (время окончания позже времени начала).
*   Бронь не может пересекаться с другой активной бронью этого же гаража.

### События
*   `BookingCreated` (создана)
*   `BookingCancelled` (отменена водителем)

## Агрегат: Гараж (Garage)
**Корень**: `Garage`
**Состав**: `Temperature` (значение), `PowerSocket` (значение).

### Инварианты
*   Температура не может быть ниже 0, если указан статус "Тёплый".
