# Единый язык (Глоссарий)

| Термин | Имя в коде | Определение |
|---|---|---|
| Гараж | `Garage` | Отапливаемое помещение для стоянки авто. |
| Бронь | `Booking` | Резервирование гаража на определенный интервал. |
| Временной слот | `TimeRange` | Полуоткрытый интервал `[start, end)`. |
| Розетка | `PowerSocket` | Наличие электрической розетки 220В (boolean). |
| Владелец | `Owner` | Пользователь, сдающий гараж. |
