# 2. Использование Python и FastAPI

- **Статус**: принято
- **Дата**: 2026-10-15

## Контекст
Нужно выбрать стек для бэкенда (ограничение C-01).

## Движущие факторы
- `C-01`: Учебный план требует Python.

## Рассмотренные варианты
| Вариант | За | Против |
|---|---|---|
| **Python + FastAPI** | Быстрая разработка, автодокументация Swagger | Медленнее, чем Go |
| Node.js + Express | Быстрый | Другой язык, не по учебному плану |

## Решение
Выбран **Python + FastAPI**. Определяющий довод: соответствие учебной программе.

## Последствия
**Отрицательные:** нужен интерпретатор Python на сервере.
