# 3. Модульный монолит

- **Статус**: принято
- **Дата**: 2026-10-15

## Контекст
Проект небольшой, команда из 2 человек.

## Рассмотренные варианты
| Вариант | За | Против |
|---|---|---|
| **Модульный монолит** | Один деплой, простота | Сложнее масштабировать |
| Микросервисы | Независимость | Слишком сложно для 2 человек |

## Решение
Выбран **Модульный монолит**.

## Последствия
**Отрицательные:** при росте проекта код может превратиться в "лапшу", нужно следить за границами модулей (Bounded Contexts).
