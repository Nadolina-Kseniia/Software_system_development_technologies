## Приоритизированный бэклог

| Приоритет | История | Обоснование |
|---|---|---|
| **Must** | Поиск тёплых гаражей на дату | Без этого сценарий не начинается |
| **Must** | Фильтр «тёплый гараж» и «розетка» | Главная зимняя ценность |
| **Must** | Бронирование на ночь | Ядро продукта |
| **Must** | Оплата и подтверждение | Без оплаты владелец не пустит |
| **Must** | QR-код или код доступа | Без доступа сценарий не работает |
| **Must** | Список броней для владельца | Иначе владелец не управляет занятостью |
| **Must** | Отмена брони | Освобождает место |
| **Should** | Продление брони | Зимой машина может не завестись |
| **Should** | Уведомление о морозе | Повышает возврат и повторные брони |
| **Should** | Отзывы и рейтинг | Доверие между людьми |
| **Could** | Реальная температура с датчика | Удобно, но не обязательно для MVP |
| **Could** | Чат с владельцем | Можно заменить уведомлениями |
| **Won't** | Автозапуск, эвакуация, страховка | Вынесено за границы объёма |
